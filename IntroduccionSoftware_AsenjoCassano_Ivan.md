¿Qué es un programa informático?

Un programa informático es un conjunto de instrucciones que tiene que seguir y cumplir un ordenador para llevar a cabo una determinada tarea. Estos programas informáticos contienen en su núcleo un código fuente, que es el texto legible por el programador y expresado en un lenguaje informático o de programación, como puede ser JavaScript, Python o C++, entre otros.

Diferencia entre código fuente, código objeto y código ejecutable.

En primer lugar, definiremos qué son estos conceptos.
El código fuente es el archivo de texto que contiene el código escrito en lenguaje de programación y que es legible por humanos, como ya se introdujo anteriormente.
El código objeto es una versión ya compilada a un formato binario del anterior código fuente, todavía no es ejecutable por un ordenador.
El código ejecutable es otra vez, un archivo de formato binario pero que ya puede ser ejecutada directamente por el ordenador.

Se puede decir que la diferencia entre estos 3 conceptos, que forman entre sí una secuencia desde el desarrollo hasta la ejecución de un programa, reside en el nivel de desarrollo del  mismo, siendo el más primitivo el código fuente, pasando por una etapa intermedia como código objeto y llegando a su fin como código ejecutable.

Etapas del desarrollo del software

Las etapas del desarrollo del software, son un conjunto de fases que van desde la concepción de la idea inicial hasta el uso y mejora del producto. Esto también se lo conoce como Ciclo de vida de desarrollo de software y consta de 7 etapas principales:
    Planificación. Define los objetivos claros del proyecto e identifica lo que se necesita para lograr dichos objetivos. Se tienen en cuenta necesidades y expectativas de la parte interesada y la viabilidad del proyecto para decidir como compilar.
    El planteamiento garantiza que todos los implicados comprenden todas las dimensiones del proyecto, lo que es esencial para evitar problemas técnicos, retrasos o la cancelación del proyecto.
    Análisis.Se debe analizar cada requisito de software para determinar como va a funcionar la solución, gracias a este análisis se pueden crear unas especificaciones del sistema que permitan el desarrollo a posteriore del proyecto.
    Diseño. Se decide la arquitectura general del software y se definen cómo los componentes clave interactuan entre sí. Al crear modelos detallados se pueden detectar de forma temprana posibles problemas y las posibles soluciones para subsanar dichos problemas.
    Desarrollo. Se traducen las especificaciones de diseño y requisitos del sistema a código real, con esto se busca compilar un sofware funcional, listo para su implementación y prueba. Gracias a esta compilación se puede revisar y refinar el código.
    Pruebas. Se ejecutan multitud de pruebas completas para asegurarse de que la solución cumple las expectativas de las partes interesadas, requisitos de seguridad y necesidade de los usuarios.
    Implementación. Tras confirmar de que el software cumple los estándares necesarios, se realiza una compilación final del software y se prepara el entorno de producción. Además, se implementan estrategias que permitan la reversión  del sistema a un estado anterior y estable en caso de que surjan problemas.
    Mantenimiento. Es una fase final y continua. El mantenimiento ayuda a garantizar el correcto funcionamiento del software, que esté protegido y que satisfaga las necesidades de los usuarios a lo largo del tiempo. Dentro de esta fase se engloba el servicio técnico, las actualizaciones, la corrección de errores y la supervisión de rendimiento.
